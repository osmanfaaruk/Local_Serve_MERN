# Collaboration Guide 🤝

To ensure you and your friend work together smoothly, follow these simple rules:

### 1. Always Pull Before You Start
Before you make any changes, make sure you have the latest work from your friend.
```bash
git pull origin main
```

### 2. Commit Frequently
Don't wait until you've done everything. Small, frequent commits are easier to manage and understand.

### 3. Clear Messages
Describe WHAT you did.
*   *Bad:* "Fixed thing"
*   *Good:* "Fixed the search button alignment on the provider page"

### 4. Resolving Conflicts
If you both edit the same file, Git will ask you to resolve a "conflict". Don't panic! VS Code makes it very easy to choose which change to keep.

*Happy coding!*
